### Meu Projeto Principal: Sistema de Gerenciamento para Prestadores de Serviço

Atualmente estou desenvolvendo o projeto **[TFC - Sistema de Gerenciamento]**, um aplicativo mobile completo construído em Flutter, projetado para otimizar a rotina de técnicos e prestadores de serviço.

| | |
| :--- | :--- |
| **O Problema:** | Prestadores de serviço autônomos e pequenas equipes muitas vezes perdem tempo e dinheiro com processos manuais, como agendamento em papel, controle financeiro em planilhas e comunicação desorganizada com clientes. |
| **A Solução:** | Um aplicativo intuitivo que centraliza o agendamento de serviços, o registro de clientes, a geração de ordens de serviço. Embora o protótipo inicial seja focado em técnicos de refrigeração, a arquitetura foi pensada para ser **flexível e adaptável a qualquer tipo de prestador de serviço** (eletricistas, encanadores, diaristas, etc.). |
| **Status:** | Em desenvolvimento (Trabalho de Fim de Curso). |

 **[Acesse o repositório do projeto aqui](https://github.com/flavioacmf/tfc)**
